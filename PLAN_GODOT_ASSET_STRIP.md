## Purpose

Per-file / per-folder triage for the reboot: which parts of the full game to **keep** (engine skeleton), which to **replace** with TODO-generated placeholders (assets — legal safety + AI-image/audio batches later), which to **remove** (unused or legally risky content), and which **new files** to create (Lichtwald content layer).

**Goal:** the minimal set that keeps the game engine **compiling and running** with a **game menu** (save-file picker → main scene) and a **first skeleton for a simple demo story** (Lichtwald Mission 01, see PLAN Phase 2c). All *content* assets (audio/images/fonts/i18n) are stripped to placeholders so the engine boots and runs, to be replaced with real (legally clean, Hannah-themed) content in a second step.

## Legend

| Mark | Meaning |
|---|---|
| ✅ **KEEP** | Copy verbatim (code/config — MIT, attribution in `game/THIRD_PARTY.md`) |
| 🔄 **REPLACE** | Keep the *path* (code references it), replace the *content* with a simple TODO-generated placeholder (SVG→PNG / silent or short loop audio / subset CSV). Flagged `TODO-IMG` / `TODO-AUDIO` for the later AI batch step (PLAN Section F). |
| ❌ **REMOVE** | Delete. Either unused by the skeleton, or third-party content that must not ship (legal). |
| ➕ **CREATE** | New file for the reboot (aim/goal in the last column). |

**Rules of thumb**
1. **Code stays** (`.gd`/`.tscn`/`.tres` classes): the engine is MIT-licensed and the plan is *copy, don't re-import*. Removing code risks breaking the engine; removing *data instances* and *assets* is safe.
2. **Assets never ship unreviewed**: every third-party audio/image/font is either replaced by a placeholder or removed. License `.txt` files are **kept** only for assets that are kept (legal record); they go with the asset.
3. **`.import` files**: always follow their asset (kept asset → keep import; removed asset → remove import; replaced asset → import regenerated by Godot on first open).
4. **`.uid` files**: follow their `.gd` file.
5. **`*.tmp`** (24 files): Godot editor temp files — always ❌.
